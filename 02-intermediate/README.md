# Generative UI — Intermediate Prototype

A sports homepage whose layout is generated by an LLM for each user, shaped by their real in-session behavior (clicks, searches, expands).

**Pipeline:** compress history → retrieve components via embeddings → generate nested layout (Gemini)

- **Gemini 2.5 Flash-Lite** returns a declarative, nested JSON layout (constrained to valid JSON) built from a fixed component catalog
- **all-MiniLM-L6-v2** runs in the browser (Transformers.js/ONNX) to select the top 10 of 19 components by cosine similarity
- **Hierarchical memory:** events beyond the most recent 10 are compressed by a second LLM call into a preference summary
- **Search vs. feed mode:** a search query alone drives retrieval; with no query, the user's history does
- **Nested layouts:** Section (collapsible), CardRow, and Tabs containers, rendered recursively
- **Debug panel:** live preference summary, similarity scores, and the event log

All sports data is generated by Gemini (no live API). The follow-up prototype adds live ESPN data.

Built with React 18, TypeScript, Vite, and Tailwind CSS. See [PROTOTYPE.md](PROTOTYPE.md) for the full technical write-up.

## Run locally

```bash
npm install
cp .env.example .env   # add your Gemini API key
npm run dev
```
