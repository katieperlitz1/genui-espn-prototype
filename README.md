# Generative UI — ESPN Prototype

A sports homepage whose layout is generated by an LLM for each user, based on their behavioral history, then hydrated with live data from ESPN's public API.

**Pipeline:** compress history → retrieve components via embeddings → generate layout (Gemini) → hydrate with live ESPN data

- **Gemini 2.5 Flash-Lite** returns a declarative JSON layout (constrained to valid JSON) built from a fixed component catalog
- **all-MiniLM-L6-v2** runs in the browser (Transformers.js/ONNX) to select the top 10 of 19 components by cosine similarity
- **Hierarchical memory:** events beyond the most recent 10 are compressed by a second LLM call into a preference summary
- **Two-phase agentic retrieval:** Gemini annotates components with `_dataSource` / `_sport` / `_league`; the app fetches those ESPN endpoints in parallel and swaps in real scores, headlines, and standings

Built with React 18, TypeScript, Vite, and Tailwind CSS. See [PROTOTYPE.md](PROTOTYPE.md) for the full technical write-up.

## Run locally

```bash
npm install
cp .env.example .env   # add your Gemini API key
npm run dev
```

The ESPN API is proxied through the Vite dev server (`/espn/*`) to avoid CORS, so live data only works in dev mode.
